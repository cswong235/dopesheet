# ![bitPile logo](./src/assets/TheDopeSheet.png)

A project built to let people store their own favourite games.

![Project Screenshot](./src/assets/Mission7.png)

Features include:
- Search function to fetch shows and movies from TVMaze
- Proper loading and error handling
- "Lucky" button to fetch 4 random shows or movies

Built with:
- JavaScript (ES6)
- React
- HTML
- CSS
- Bootstrap
